# **Bayesian Item Response Theory (IRT)-based Examination Scoring with PyMC**

This repository contains a complete implementation of a Bayesian Item Response Theory (IRT) model, specifically the 2-Parameter Logistic (2PL) model, built from scratch using PyMC.

This project focuses on latent ability estimation, item characteristic analysis, uncertainty-based inference, and score transformation for assessment purposes.

## **Background and Case**

In conventional exams, examinees are measured and graded based on the number of correct answers. Exams can contain varying levels of question difficulty. By calculating scores based on raw scores (number of correct answers), two examinees who correctly answer the same number of questions can receive the same score, even though they may have answered questions correctly at different levels of difficulty. This results in the final score not representing the examinee's latent ability to answer the questions. With the IRT model, examinees' latent abilities can be measured, resulting a more representative score. The final score generated by the IRT model can be used for selection examinations to truly create a selection system that filters out superior examinees.

## **Project Overview**
This project focuses on building a Bayesian IRT model used for scoring examinees' answers. Item Response Theory (IRT) is a core framework in educational measurement used to estimate examinee ability and item characteristics beyond raw scores. In this project, I implement a **Bayesian 2PL IRT model** to:

- Estimate latent ability $(\theta)$ for each examinee  
- Estimate item discrimination $(a)$ and item difficulty $(b)$ parameters  
- Quantify uncertainty via posterior distributions  
- Analyze Item Characteristic Curves (ICC) and Item Information Curves (IIC) 
- Transform latent ability estimates into an interpretable final score scale

## **Dataset Description**
The dataset used in this project is a dataset containing examinees' answers. 
- Number of examinees: 1,000
- Number of items: 25
- Response format: Binary (0 = incorrect, 1 = correct)

As a **disclaimer**, the answer data provided is synthetically generated, not real data. The dataset can be accessed through Kaggle [here](https://www.kaggle.com/datasets/ahmadfarhanh/examinees-answers).

## **Model Specification**

This project uses a **Bayesian 2PL IRT model**, defined as:

$P(Y_{ij} = 1 \mid \theta_i, a_j, b_j) = \sigma \big( a_j (\theta_i - b_j) \big)\$

Where:
- $\theta_i$ : latent ability of examinee *i*
- $a_j$ : discrimination parameter of item *j*
- $b_j$ : difficulty parameter of item *j*
- $\sigma(\cdot)$ : logistic sigmoid function

### **Priors Setting**
- $\theta_i \sim \mathcal{N}(0, 1)$
- $a_j \sim \text{HalfNormal}(1)$
- $b_j \sim \mathcal{N}(0, 1)$

These choices ensure:
- Model identifiability
- Positive discrimination values
- Weakly informative regularization

### **Posteriors Inference**
Posterior inference is performed using:

- Markov Chain Monte Carlo (MCMC)
- No-U-Turn Sampler (NUTS)

Key sampling settings:
- `draws = 2000`
- `tune = 1000`
- `target_accept = 0.9`

NUTS is chosen for its efficiency in high-dimensional, correlated posterior spaces commonly found in hierarchical IRT models.

## **Model Diagnostics**

The notebook includes:
- trace plots for $\theta$, $a$, and $b$,
- convergence diagnostics (`R-hat` ≈ 1.0), and
- Effective Sample Size (ESS) checks.

These diagnostics confirm that the posterior samples are stable and reliable.

## **Item Analysis**

### Item Characteristic Curves (ICC)
- Visualize how the probability of a correct response varies with ability
- Highlight differences in item difficulty and discrimination

### Item Information Curves (IIC)
- Show where each item provides the most measurement precision
- Demonstrate that some items are informative at low ability levels, while others target high-ability examinees

Extreme items (very easy or very difficult) are intentionally retained to illustrate how IRT captures measurement precision across the full ability spectrum.

## **Ability Estimation and Scoring**

- Examinee ability is estimated using the **posterior mean of θ**
- No z-score normalization is applied
- Final scores are produced using a **linear transformation**:

$\text{Score} = 500 + 100 \times \theta$

This transformation:
- preserves rank ordering;
- produces an interpretable scale;
- represents the relative latent ability of the examinee; and
- aligns with common standardized testing practices.

## **Key Insights**

- Examinees with identical raw scores may receive different IRT scores due to item difficulty weighting
- Items with extreme proportions correct can still be informative if their IIC is well-localized
- Bayesian inference provides richer insight by explicitly modeling uncertainty
